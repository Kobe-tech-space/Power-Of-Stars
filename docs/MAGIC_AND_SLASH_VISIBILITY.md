# 魔法伤害分类与剑气可见性

未发布版本统一使用1.0.0-1.20.1，功能保留最新实现；不要因文件名与旧版本相同而同时保留两份JAR。

## 当前剑气伤害

物理半段：`tutorial_mod:astral_slash`，加入`forge:is_physical`，按目标护甲处理。

魔法半段：`tutorial_mod:astral_slash_magic`，加入`minecraft:bypasses_armor`、`minecraft:witch_resistant_to`、`forge:is_magic`。它是自定义魔法伤害类型，行为类似原版间接魔法的护甲穿透，不是直接使用原版`minecraft:indirect_magic`。保留剑气实体、玩家归属和弹射物分类。

魔法不是无条件真实伤害：仍可被抗性、保护类附魔、护盾、模组免疫和第三方事件处理影响。没有向所有魔法模组承诺其法强、魔抗、元素系统会自动兼容；本次补充的是常用Forge分类标签。

两半共用一道剑气的视觉，不用颜色区分伤害。攻击无护甲且无其他减伤的目标时，两半实际伤害一样，因此看伤害数字可能感觉没区别。

独立GameTest实测：总基础伤害20，目标护甲20、韧性0，物理10被护甲减至4，魔法10保留10，合计扣血14。两段结算没有被本次物理命中的受击无敌时间吞掉。两项必需服务端测试均通过，记录见`docs/art/mixed-damage-check-latest.log`。

## 剑气显示

当前按用户要求恢复原来的月牙角度、颜色、透明度、刃芯与拖尾，仅整体放大到原来的1.65倍。上一轮新增的55度倾角及主体混合方式已撤销。没有新增贴图或提高粒子生成频率。此前白天／夜间截图是上一轮的历史效果，不是当前朝向的预览。

只改变渲染尺寸，不扩大命中范围、不提高伤害，不修改飞行方向、速度、16道上限或5秒寿命。暴击计算保留，但不恢复暴击专属浮字、音效或换色。

此文以当前源码与独立测试为准；用户整合包或光影可能对渲染及伤害事件进一步修改。
