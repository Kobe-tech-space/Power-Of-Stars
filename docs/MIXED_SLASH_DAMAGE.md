# 1.1.3：剑气混合伤害

> 当前未发布版本统一1.0.0，已补充Forge魔法／物理分类，并完成两段伤害服务端实测，详见[魔法伤害与剑气可见性](MAGIC_AND_SLASH_VISIBILITY.md)。

剑气总伤害拆为50％物理与50％魔法，适用于普通、三重、八方、穿透及雷雨连锁剑气。近战与五层星痕爆发不改变。

总伤害100时，进入伤害流程的是50物理和50魔法；减伤后的实际扣血不一定仍各占一半。魔法半段使用独立类型`tutorial_mod:astral_slash_magic`，绕过护甲及本模组额外护甲补偿，保留弹射物标签、女巫魔法抗性、抗性、保护附魔、护盾及免疫处理，不是真实伤害。第三方魔法属性能否识别该类型取决于其自身规则。

仅物理半段成功后临时解除其造成的受击无敌时间，再结算魔法半段并恢复保护；不全局关闭目标无敌时间。物理半段击杀后不伤害尸体。两段保留同一玩家和剑气归属，命中统计、星痕、熟练度及进攻星能只计一次；暴击实际伤害合计两段有效伤害。

保留1.1.2攻击输入兼容。构建及输入去重单元测试通过，不代表已在用户整合包完成实际战斗测试。本次不修改整合包文件或存档。
