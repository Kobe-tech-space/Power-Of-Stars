# 饰品库存图标清晰度修正

原来的1254×1254饰品原画在物品栏的16×16显示区域中，细链、金边、银河纹理和高光混成碎光，导致外形难以辨认。本版使用内置imagegen，以每张原画为编辑参考，逐件重绘十个库存图标。

## 设计变化

- 原生32×32透明贴图，主体尽量填满图标区域。
- 更粗的深靛色描边、大面积蓝紫宝石色块、简洁金色边框。
- 保留各自的形状：项链、戒指、翼形胸针、月牙耳坠、王冠、腕环、水滴吊坠、星罗仪、星形徽记、圆形月纹护符。
- 减少细链、散点高光和多个悬挂宝石，强调外轮廓和不同形状。
- 功能、物品ID、配方和饰品位规则不变，版本仍为1.0.0。

## 文件

- `prompts.json`：十次内置imagegen编辑的完整提示词和原图路径。
- `manifest.json`：生成结果与物品ID的对应记录。
- `generated_masters`：生成的高分辨率母版，已保存到项目内。
- `original_hd`：替换前的十张高清贴图备份；用户原始图片目录未修改。
- 实际资源：`src/main/resources/assets/tutorial_mod/textures/item` 下对应十个饰品PNG。

`scripts/ImportOrnamentIcons.ps1`仅负责生成结果的透明边界裁切、居中和最近邻尺寸转换，不改变饰品美术设计。默认输出32×32，可显式指定Size。

验证使用真实Minecraft创造物品栏及原生物品模型，而不是仅使用放大展示。测试用例和验证界面不进入发布JAR。
