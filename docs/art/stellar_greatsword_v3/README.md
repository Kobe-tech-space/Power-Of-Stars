# 星环重剑 · 星辰君临

重新设计的银白／蓝紫星辰大剑，包含尖锐多层刃面、星河通道、金边星纹、成对星翼护手、双轨星环、中央八芒星核和宝石剑首。

## 工程与贴图

- `stellar_sovereign.bbmodel`：Blockbench Minecraft Java方块／物品工程，内嵌1024×1024透明贴图。
- `stellar_greatsword_v3.png`：实际游戏贴图。
- `original_generated_texture.png`：内置image_gen生成的原始透明素材。
- `ice_sword.json`：实际游戏模型。
- `IMAGE_PROMPT.txt`：原始生成提示词。

在Blockbench使用“文件→打开模型”打开`.bbmodel`。Blade、Twin star wings、Grip三个分组可编辑。保存修改后导出Java模型，贴图引用为`tutorial_mod:item/stellar_greatsword_v3`。

## 对称与立体结构

模型为浮雕式立体武器，不是单张平面：206个方块，分为103组左右镜像对，深度根据剑刃、剑脊、护手与星核分层。未旋转的局部构型沿X=8完全镜像，左右坐标、厚度和UV映射均配对。背面也有对应纹理，不是空白背板。

1.1.8将剑的局部方向调整为原版剑贴图的斜向轴，并完全沿用原版handheld.json的四组左右手第一／第三人称旋转、平移和缩放设置；不是仅复制角度却忽略模型本身方向。物品栏展示补偿保持完整剑形。

之前整剑256×256贴图让狭窄剑刃只剩几十像素宽，金边与星纹丢失。当前使用1024×1024贴图，网格轮廓仍用256采样以限制模型构件数量，贴图UV直接读取高清纹理，二者不混用分辨率。背包小图标的屏幕像素数有限，不保证能显示所有细纹；资源包、光影、抗锯齿或缩放也可能影响清晰度。

对称通过模型几何与UV实现，不通过人工覆盖原始图片。图像生成工具负责专用剑身纹理，脚本进行最近邻规格转换、轮廓网格化、分层厚度与镜像UV。这样在游戏中的左右颜色和星纹也完全一致。

新版本1.1.8修正持握角度和贴图规格，保留物品ID、NBT、伤害、技能、强化、悬赏与领域设定。没有改变用户实际整合包或存档。旧v2工程保留，方便比较与恢复。
