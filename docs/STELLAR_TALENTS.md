# 星辰天赋与专属附魔

## 使用

按O或输入 `/astral talents` 打开独立星座式天赋树，按键可在设置中重新绑定。选择节点后点击“投入1点”。悬停节点查看效果及前置条件。服务器关闭系统时界面不可加点。

使用星环重剑近战或剑气击杀敌对怪物，默认每次获得10天赋经验。首点需100经验，后续每点需求增加25；累计9300经验达到24点上限。每节点最高3级，每级1点，后续节点需前一个达到2级。总计36级但只能分配24点，需要选择流派。

经验和加点随玩家保存，死亡、重登、跨维度保留。洗点默认消耗5级原版经验和8星锭，需第二次点击确认；创造免费。洗点不扣天赋经验，退还全部已分配点数，不会重复增发点数。

## 六种附魔（最高III级）

| 附魔 | 装备 | 每级效果 |
| --- | --- | --- |
| 星锋 | 星环重剑 | +8%加算伤害，包含近战与剑气 |

| 星噬 | 星环重剑 | 汲取1%实际命中伤害为生命 |
| 星障 | 两阶星辰胸甲 | +1%加算伤害免疫 |
| 星行 | 两阶星辰靴子 | +3%加算移速 |
| 星铸 | 两阶星辰胸甲 | 完整套装每10秒修复1耐久，每件损坏装备消耗1星能 |

通过附魔台获取，或用原版铁砧施加附魔书。创造模式独立分类包含所有等级。附魔描述模组所需的中英文 `.desc` 翻译已内置；帕秋莉手册“战斗与技能”新增两篇说明。

聚星、星噬和吸血天赋共享每名玩家每秒一次的触发窗口。吸血每次最多2点生命，按减伤后的单次伤害计算，剑气的物理/魔法两段不会分别吸血。星铸与养护相加；默认跳过带经验修补的装备，并遵守 `repair.enabled` 开关。只修复星辰武器和盔甲，不会修复其他物品。

## 配置与联机

世界的 `serverconfig/tutorial_mod-gameplay.toml` 新增 `talents.enabled`、`talents.killExperience`、`talents.resetLevels`、`talents.resetIngots`。关闭天赋不会删除存档，专属附魔仍可使用。所有消费、前置与等级校验由服务端处理；客户端不能提交经验或等级。天赋属性使用固定UUID，不累加重复修饰符，换装或洗点撤销。

网络协议更新，服务端和客户端都需要使用这次导出的JAR；对外模组版本保持1.0.0。没有新增贴图、怪物或第三方前置。

## 调研与授权边界

本次验证：12项单元测试、4项专用服务端GameTest通过；实际客户端验证了打开天赋界面、发送加点请求及服务端确认，并检查了界面截图。中英文手册各40个条目通过结构校验。

参考 [Pufferfish’s Skills](https://github.com/pufmat/skillsmod/tree/1.20) 的节点/经验/前置设计，以及 [Passive Skill Tree](https://github.com/Daripher/Passive-Skill-Tree/tree/1.20.1) 的玩家存档、属性撤销和洗点思路。本功能全部独立实现，未复制、嵌入或移植这些项目的源码、界面纹理和图标。
