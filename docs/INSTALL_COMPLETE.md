# 星环模组完整交付：Forge 1.20.1

## 安装

1. 退出 Minecraft，先备份准备游玩的存档。
2. 用本包 `mods/tutorial_mod-1.1.0-1.20.1.jar` 替换旧版星环模组。不要同时保留多个本模组 JAR。
3. 帕秋莉是必需依赖。本包附有 `Patchouli-1.20.1-84.1-FORGE.jar`；整合包已有兼容的 Forge 帕秋莉时保留一份即可，不要重复放入或使用 Fabric 版。
4. 联机时服务器和所有客户端同步更新。本版协议11，不与旧版混用。
5. 启动游戏，进入已有世界即可。新矿物配置只影响新生成区域，不修改旧地形。

本版要求 Minecraft1.20.1、Forge47.4.10或更新的47.x、Java17；已验证Forge47.4.10。也验证了 Apothic Attributes1.3.7 + Placebo8.6.3 的组合；它们是可选兼容模组，本包不额外安装。不能保证所有第三方整合包组合都具有相同伤害或平衡。最低版本门槛用于防止旧Forge缺少本模组所需API时发生难以定位的启动错误。

## 主要入口

- L：独立悬赏界面，10项一次性任务；先接取、完成后手动领奖。
- K：简洁 HUD 自定义。
- 重剑右键：切换近战/剑气；潜行右键：切换熟练度分支。
- V / 潜行V：三重斩 / 环形斩。
- G：重铸星能盾，默认花费150星能恢复50点盾。
- J：进阶四件套领域，默认花费1000星能，保持既有破军/统御设定。
- N / R / H：星感知 / 冲刺 / 安全短距瞬移。
- 潜行主手持星环装备右键锻造台：固定成本强化，最高+5。普通低阶→高阶升阶仍使用锻造台三槽配方。
- 高炉：未附魔装备耐久回收；附魔装备先过砂轮。
- 首次重剑自动赠帕秋莉手册；也可用书和星锭合成。
- Esc→进度：星环之路；Esc→统计信息→通用：星环统计。
- `/astral help`：操作帮助；`/astral stats`：个人统计。

以上按键均可在 Minecraft 的按键设置中重新绑定；整合包同键冲突请更换对应按键。

## 配置与本版规则

世界目录 `serverconfig/tutorial_mod-gameplay.toml` 是新增世界级服务端配置，由Forge同步客户端。既有获取/衰减/剑气射程设置仍在 `config/tutorial_mod-common.toml`；HUD在 `config/tutorial_mod-hud.toml`。建议退出世界后修改，再重启。

默认保留初阶250 / 进阶1000星能、星能盾50、守护屏障1000、暗紫剑气和星辰粒子。剑气硬上限16道、100刻（5秒）。普通未强化剑气命中首个目标消失；强化+2/+4分别穿透2/3个目标。领域不享受强化减耗。暴击伤害与统计保留，不恢复暴击音效、震动、高亮或浮字。

天气与环境增益默认关闭，可在environment下逐项开启。手册参考分类已加入21–32类；详细成本和兼容边界见同包 `FEATURES_21_32.md`，悬赏清单见 `BOUNTIES.md`。

本包只交付文件，不自动修改实际整合包、安装目录或个人存档。
