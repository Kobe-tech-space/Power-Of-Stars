# 自定义星环 HUD

进入世界后按 K 打开编辑器。按键可在控制设置的“星环装备”分类中重新绑定。
模组列表中本模组的“配置”按钮也会打开此编辑器。

拖动方框调整位置；滚轮调整选中元素大小；方向键精调位置，按住 Shift 时每次移动十个预览像素。
左右箭头切换元素，可单独设置显示、大小（50%～200%）、透明度（20%～100%）。
编辑器默认全屏预览，点击右上角“选项”或按 Tab 展开设置面板。
面板按钮调整全局 HUD、边缘特效、青蓝/星紫/金色配色，也可恢复默认。
“保存返回”或 Esc 保存并退出；设置写入本机 `config/tutorial_mod-hud.toml`，不改变服务器设置。
编辑器使用示例资源与连击数据，方便调整未触发的元素。
位置按屏幕比例保存，游戏中会将元素限制在可见区域内。

新版默认只有一个统一状态面板：模式与等级、星能、星能盾和守护屏障，窄边、细条、统一配色。基准尺寸148×62预览像素，默认80%缩放，靠左下并避开快捷栏。连击条可选，默认关闭。面板及连击条仍可分别拖动、缩放和调整透明度。

领域改为原版药水图标，不再绘制领域时长或冷却倒计时；暴击浮字永久关闭。旧分散元素的配置键保留作兼容，但不再绘制。当前有效 Forge overlay 是 `tutorial_mod:astral_panel` 和 `tutorial_mod:astral_combo`。
升级时一次性切换到新版紧凑布局，以后不会每次启动重置。边缘闪屏默认关闭，可在编辑器选项中手动打开。
隐藏原版快捷栏不会自动隐藏星环 HUD。第三方模组能否调整这些 overlay，取决于它提供的兼容方式。

如果还需要修改原版生命、饥饿或经验栏，可另外选择对应 Forge 1.20.1 的 HUD 模组；本编辑器负责本模组的专属界面。
