## 1. 模组定位与安装

星环是以“星矿—星锭—重剑与盔甲—星能技能—终局领域”为主线的战斗、装备成长与探索模组。它在原版生存流程上增加远程剑气、两阶高属性盔甲、专属附魔、熟练度、固定成本强化、精英怪、信标试炼和独立悬赏。

本模组偏高强度装备与终局战斗，不是轻量原版数值扩展。尤其进阶套装、至尊锋利和破军领域，会显著提高玩家输出；整合包作者应结合敌人强度调整配置。

### 安装要求

- Minecraft：1.20.1。
- 加载器：Forge 47.4.10或更新的47.x版本。
- Java：17及以上兼容运行环境；一般使用整合包指定的Java环境。
- 必需依赖：Patchouli，已验证 `Patchouli-1.20.1-84.1-FORGE`。
- 可选：Enchantment Descriptions及其匹配版本Bookshelf，用于附魔效果说明。
- Apothic Attributes属于可选兼容模组，不是必需依赖。

退出游戏、备份存档，将新版JAR放入`mods`并移除旧版本JAR。不要同时安装两份本模组，也不要混用Forge与Fabric文件。联机时服务器和客户端都应更新；当前网络协议为11。

模组注册标识仍为`tutorial_mod`，不是`cosmic_armor`。创造模式有独立“星环装备”分类，图标为重剑，包含15种物品及全部正常等级的模组附魔书；原版分类不再重复放入这些物品，全局搜索仍可找到。

## 2. 新手入门与材料

推荐流程：寻找星矿 → 烧炼星锭 → 合成重剑和初阶四件套 → 战斗获取星能 → 使用技能、试炼和悬赏 → 收集终局材料升阶 → 按需要强化装备。

### 星矿

星矿具有适配装备的星辰配色，并发出微弱光亮。使用合适的镐采集，掉落星矿方块，再烧炼成星锭。

默认生成参数如下。次数是每区块的放置尝试次数，矿脉大小不是保证产量：

| 地区  | 每区块尝试 | 矿脉大小 | 高度范围     |
| --- | -----:| ----:| -------- |
| 主世界 | 6     | 6    | Y=-32～48 |
| 末地  | 3     | 5    | Y=0～80   |

配置只影响新生成区块，不会给已经探索的区域补矿。

### 基础配方

- 星矿 → 星锭：支持熔炉及高炉；普通熔炉耗时200刻，提供0.7经验，高炉耗时100刻。
- 9块星锭 → 1块星锭块，可拆回9块星锭。
- 书 + 星锭 → 星环装备指南，无序合成。
- 初阶盔甲使用星锭，按原版头盔、胸甲、护腿、靴子的形状合成；全套共24块星锭。
- 星环重剑：两块星锭与一根木棍纵向排列，形状与原版剑相同。

```text
空  星锭  空
空  星锭  空
空  木棍  空
```

首次获得星锭会解锁相关配方并提供可点击帮助；首次制作重剑会自动赠送帕秋莉手册，自动赠书可以关闭。

## 3. 重剑、剑气与成长

### 星环重剑

基础面板攻击力30、攻击速度2.5、基础耐久25000。这里是未计套装、附魔、药水与其他模组属性的基础值，不代表每一击必定造成30点生命损失。

- 主手持剑右键：切换破军近战／统御剑气攻击模式。
- 近战：普通近战攻击，已取消此前的自定义重剑横斩动作。
- 剑气模式：使用攻击键挥出暗紫色月牙剑气，朝准星方向飞行。
- 潜行右键：切换重剑专精，不是切换攻击模式。

“破军／统御”既用于区分攻击模式，也用于对应领域名称。切到统御模式本身不会获得无敌或屏障，必须满足条件后按J释放领域。

### 剑气规则

- 不设置普通剑气的玩法冷却；仍保留同刻防重复与网络请求限速。
- 每名玩家同时最多16道，最长存在100刻，即正常20TPS下5秒。
- 默认最远距离96格，碰撞、命中、距离、离线或换维度清理可能让它提前消失。
- 默认飞行速度1.1；技能剑气速度1.35。
- 未强化剑气命中首个有效目标后消失；重剑强化+2/+3可命中2个，+4/+5可命中3个。
- 同一道剑气不会反复伤害同一个目标。
- 发射时保存伤害加成、暴击结果、武器附魔和强化状态，飞行途中换武器或BUFF结束不会重新计算整套发射数值。
- 命中产生星辰爆散反馈，击杀产生更强碎裂效果；空挥与命中音效区分。
- 默认保护自己的驯服宠物、创造／旁观玩家等无效目标，并遵守原版队伍友伤规则。

原版锋利、亡灵杀手、节肢杀手的目标加成从发射武器快照读取；火焰附加可点燃目标，击退影响击退，抢夺在掉落时读取发射瞬间等级。剑气不执行近战横扫之刃或近战荆棘回调。实际伤害仍经过目标护甲、保护、抗性等伤害流程。

### 熟练度与专精

熟练度保存在每把重剑上，最高20级，每级需要100熟练经验。有效重剑／剑气命中增加熟练经验，相关击杀也提供经验。命中时成长写入当前主手重剑，因此剑气飞行途中换走重剑，不保证给已收起的原剑增长熟练度。

每级提供1％熟练度伤害加成，20级为20％。满级武器在提示框中显示“星主”前缀；自定义名称会受到尊重。

| 专精  | 作用                |
| --- | ----------------- |
| 星刃  | 近战伤害提高15％         |
| 月痕  | 剑气伤害提高15％         |
| 星核  | 每次符合条件的星能获取额外增加1点 |

主手重剑与每件星环盔甲各计1级装备共鸣，最高5级；混穿也可贡献共鸣，但不意味着解锁完整套装。剑气伤害计算中每级共鸣提供2％加成，5级为10％。

### 星痕与连击

有效重剑近战／剑气伤害会给目标叠加星痕。星痕间隔超过6秒后重新累积；第5层引爆，基础爆发伤害为`12 + 重剑熟练度等级×0.5`，还会短暂施加发光、缓慢与粒子反馈。最终扣血仍取决于伤害处理链。

“越战越勇”附魔启用连击成长：50／100／150连击对应伤害独立乘以1.5／2／2.5。超过30秒未造成相关命中后，下一次重新从1开始；退出、换维度等生命周期清理也会重置临时连击。

## 4. 两阶盔甲与伤害计算

初阶为星环套装，进阶为高阶星辰套装，具有独立模型、物品图标和头后光环。

下表均为默认配置。全套数值包含四件及全套额外奖励：

| 属性     | 初阶单件  | 初阶全套 | 进阶单件  | 进阶全套 |
| ------ | -----:| ----:| -----:| ----:|
| 护甲     | 20    | 100  | 50    | 250  |
| 韧性     | 50    | 200  | 50    | 200  |
| 模组伤害免疫 | 5％    | 30％  | 10％   | 60％  |
| 同类加算攻速 | 2％    | 13％  | 5％    | 30％  |
| 同类加算增伤 | 2％    | 13％  | 5％    | 30％  |
| 星能容量   | 不单独解锁 | 250  | 不单独解锁 | 1000 |

初阶四件之外额外提供20护甲、10％免疫、5％攻速及5％增伤。进阶四件之外额外提供50护甲、20％免疫、10％攻速及10％增伤。

### 完整套装效果

- 初阶：80％额外摔落减伤（摔落缓冲X的实现）、抗性提升I、力量II、急迫II、夜视、熔岩明视。
- 进阶：摔落伤害免疫、抗火、力量X、急迫X、夜视、熔岩明视。
- 两阶：头后星环、星能获取与技能资源、星能盾重铸。

必须四件同阶。混穿只有单件属性，不提供同阶全套奖励、套装药水效果或正常星能容量。脱下完整套装会结束依赖套装的效果。

熔岩明视改善岩浆雾视距并隐藏岩浆中的火焰遮挡；初阶的明视不提供抗火，仍会受到岩浆伤害。第三方光影可能覆盖雾与火焰渲染。

### 如何理解加算与乘算

套装增伤与超级／究极锋利等同类百分比先相加，再应用至尊锋利等独立乘区。例如初阶全套与超级锋利I的这一部分系数为`1 + 0.13 + 0.20 = 1.33`，不是`1.13×1.20`。

免疫也是先与本模组对应属性加算，再与护甲、抗性等其他机制组合；最终免疫比例有安全上限95％。进阶“60％免疫”不是把全部伤害机制合计后的最终减伤率。

本模组提高护甲／韧性属性可用上限，但不会降低其他模组已经提高的上限。检测到Apothic Attributes时关闭旧的额外护甲补偿，避免重复叠加；其他模组的伤害公式、额外属性仍可能改变结果。

## 5. 星能、护盾与领域

### 星能获取

正常获取要求完整同阶套装。默认命中+5、击杀+15、暴击额外+3；星核专精、星辉事件或开启的环境配置可进一步影响获取。

初阶上限250，进阶上限1000。停止相关战斗获取10秒后，默认每秒衰减1点。死亡默认不保留星能；可用服务端配置开启保留。脱装后正常容量为0，不能把脱装当作储能手段。

### 两种护盾，不是额外生命

| 类型   | 获取          | 默认数值 | 保留规则                     |
| ---- | ----------- | ----:| ------------------------ |
| 星能护盾 | G，消耗150星能重铸 | 50   | 脱装或死亡清除                  |
| 守护屏障 | 统御领域        | 1000 | 领域结束、脱装、离线及死亡后保留剩余值，直到击碎 |

重铸／再次统御是恢复到对应数值，不叠加无限护盾。受到需要吸收的伤害时，守护屏障先吸收，再到星能护盾，超出部分扣血。

两者独立记录，不使用金苹果的黄色吸收生命槽，不覆盖正常金苹果吸收效果。当前没有“穿齐自动获得250额外生命”的旧机制。

### 领域：J

条件：进阶同阶四件套、主手星环重剑、默认1000星能、对应领域不在冷却。普通生存释放扣1000点，不是扣任意剩余星能；强化不会降低领域消耗。

| 模式／领域 | 时长  | 冷却   | 效果                                    |
| ----- | ---:| ----:| ------------------------------------- |
| 近战／破军 | 10秒 | 300秒 | 攻击力×3、攻速×3、伤害×1.5，分别为独立乘区             |
| 剑气／统御 | 10秒 | 300秒 | 拦截单次原始伤害大于1的伤害、拒绝负面及中性不利状态、给予1000守护屏障 |

破军不是简单的“总伤害增加50％”；它还改变攻击力与攻速。最终输出取决于武器、BUFF、目标和其他模组。

统御的状态免疫只在释放后的10秒领域状态有效。监守者黑暗、失明等会被清理和拦截；1点及以下伤害不被领域阈值直接免疫，但仍可被护盾吸收。无法保证阻止其他模组绕过正常伤害／状态事件直接改生命或自定义视觉的行为。

两种领域分别冷却，切换攻击模式不会自动释放或重置冷却。脱下进阶完整套装、喝奶移除状态或效果结束后，不再享有领域状态免疫；守护屏障仍按自身规则保留。创造模式领域免星能、免冷却。

领域通过真正的状态效果显示：破军使用星辰奇点图标，统御使用金色奇点图标。HUD不额外显示领域时长倒计时。

所有按键可在“选项→控制→按键绑定”修改。下表为默认消耗，装备强化可能降低普通技能消耗。

| ------ | ------- | -------------------- |
| 重剑右键   | 近战／剑气切换 | 无星能消耗                |
| 潜行重剑右键 | 专精切换    | 星刃→月痕→星核循环           |
| V      | 三重星环斩   | 50星能、主手重剑、须有3道剑气名额   |
| 潜行+V   | 八方星环斩   | 75星能、主手重剑、须有8道名额     |
| B      | 完美防御    | 15星能、主手重剑，窗口8刻，约0.4秒 |
| G      | 重铸星能护盾  | 150星能、同阶全套、护盾未满      |
| J      | 对应模式的领域 | 1000星能、进阶全套、主手重剑     |
| N      | 星感知     | 10星能、同阶全套，间隔5秒       |
| R      | 星跃短距移动  | 20星能、同阶全套，间隔2秒       |
| H      | 星环传送    | 40星能、同阶全套，间隔5秒       |

普通技能剑气默认每道以攻击力的0.75为基础，再应用对应加成。完美防御在短窗口内取消一次受击，并击退可识别的攻击者，不是常驻无敌。

星感知扫描脚下坐标各轴±12格的立方区域，只报告最近星矿的东／西／南／北及大致距离，不画透视框；未找到也会消耗星能。

星跃沿视线移动最多3.5格，星环传送最多8格。服务端逐步检查碰撞、加载区块、世界边界、高度和液体；遇到不安全位置提前停止，无法移动足够距离时不扣资源。当前不是穿墙传送，也不跨维度。

当前探索技能不是“戴头盔即可扫描”或“双击跳跃一次空中冲刺”；这些是早期建议，不是本版的操作方式。

## 8. 升阶、强化、维修与回收

### 升阶：初阶盔甲变为进阶盔甲

打开锻造台界面，将**星辰升级模板／初阶盔甲／星辰奇点**放进三个对应槽位。四个部位分别升级，沿用锻造配方的数据复制机制，保留附魔、自定义名称、强化等级与已有耐久损耗。

星辰奇点配方：

```text
下界合金锭  钻石块      下界合金锭
星锭块      下界之星    星锭块
下界合金锭  钻石块      下界合金锭
```

星辰升级模板配方：

```text
钻石块      下界合金锭          钻石块
星锭块      下界合金升级模板    星锭块
钻石块      下界合金锭          钻石块
```

升阶全套需要4下界之星、24下界合金锭、24钻石块、16星锭块、4原版下界合金升级模板，以及原有初阶四件套。这里的材料不包含初阶四件套自身的24块星锭。没有廉价模板复制配方；重剑没有这一套低阶盔甲升阶配方。

### 强化：同一件装备增加+1～+5

这是另一套独立系统，不替代升阶。**潜行，主手持重剑或本模组盔甲，右键锻造台方块**触发；材料从背包扣除，不是填入锻造台三个槽位。

| 本次升到 | 星锭  | 钻石  | 经验等级 | 星辰奇点 |
| ---- | ---:| ---:| ----:| ----:|
| +1   | 2   | 2   | 5    | 0    |
| +2   | 4   | 4   | 10   | 0    |
| +3   | 8   | 6   | 15   | 0    |
| +4   | 16  | 8   | 20   | 1    |
| +5   | 32  | 10  | 25   | 1    |

固定成本、没有失败概率。每一级分别支付，经验消耗的是等级，不是经验点；材料不足或达到上限不扣材料。创造模式免费。

- 每级最大耐久+10％，+5为基础耐久的150％；重剑+5为37500。
- 主手与四件盔甲的总强化等级，每级让普通技能消耗降低0.8％，总上限20％，费用向上取整。
- 领域不参与减耗。
- 重剑+2／+4分别解锁2／3目标剑气穿透。
- 强化等级存入装备数据，保留原物品ID、名称和附魔；不是创造新的物品类型。

### 维修

- 星锭可以在铁砧维修重剑和盔甲。
- 满星能时每200刻，默认给手中重剑恢复10耐久。
- 精英击杀默认25％概率给符合条件的手中装备修复100耐久。
- 默认自动维修不与经验修补叠加；可配置放开。
- 重铸及领域默认让穿戴的各件盔甲损耗1耐久，创造模式免损。
- 祭坛还有单独的修复规则，见下一节。

### 高炉回收

9种装备均可通过高炉回收，包括重剑、初阶四件和进阶四件。装备必须无附魔，有附魔先使用砂轮处理。

胸甲最多回收2星锭，其余最多1星锭。实际数量按剩余耐久比例向上取整；耐久耗尽为0。不会返还奇点、模板、强化材料或经验；不能通过合成—回收循环复制资源。支持高炉自动化，不是普通熔炉回收。

## 9. 精英、试炼、祭坛与星象

### 星蚀精英

符合条件的敌对生物默认有3％概率变为精英；星蚀事件期间默认14％。已自定义名称或原始最大生命至少200的敌人不参与普通随机升格。精英有显眼名称、发光和类型粒子。

共同强化包括生命、12额外护甲、8额外韧性、攻击、移动与击退抗性。生命加成按原始生命计算，最多提升至6倍，并以500生命为计算目标。例如基线生命20的敌人提升到120，基线100提升到500；不是所有精英固定500生命。这些例子不包含其他模组随后修改属性的影响。

| 类型   | 特征                  |
| ---- | ------------------- |
| 狂暴星蚀 | 更高攻击加成，半血后周期获得力量与速度 |
| 星盾星蚀 | 初始80吸收盾，脱离受击后周期修盾   |
| 迅捷星蚀 | 更高移速，满足距离及视线条件时突进   |
| 引力星蚀 | 近距离吸引目标，周期攻击并施加缓慢   |

击杀精英额外掉落3～6星锭，并可触发自动耐久恢复。精英属性不会因重复加载而不断叠加。

### 信标试炼

主手星锭右键信标启动，消耗1星锭；创造不消耗。试炼不要求祭坛结构。

总共3波，依次5／7／9只怪物，以骷髅、僵尸、蜘蛛组合生成；第三波包含强化精英。清完当前波后进入下一波；离开信标中心64格范围失败。完成获得4星锭、300经验点，并记录神话悬赏的试炼进度。

建议在平坦开阔区域启动。怪物生成位置参考地表高度，不是一个隔离副本；不承诺复杂地形下具有专门的寻路或防卡怪保证。

### 星环祭坛

在同一水平面构建下列3×3结构，主手星锭潜行右键信标，消耗1星锭激活：

```text
哭泣黑曜石  紫水晶块  哭泣黑曜石
紫水晶块    信标      紫水晶块
哭泣黑曜石  紫水晶块  哭泣黑曜石
```

祭坛把星能恢复到当前套装上限，修复穿戴盔甲各500耐久，并修复背包中第一把符合条件的损坏重剑1000耐久。没有完整套装时正常星能上限为0。祭坛不免费重铸星能盾，也不增加守护屏障；盾仍使用G或统御获取。

### 世界星象事件

主世界每个新游戏日进行一次28％概率判定，触发后随机选择一种星象，持续12000刻，约10分钟：

- 星落之夜：破坏星矿有50％概率额外掉落一块星锭。
- 星辉时刻：星能获取倍率提高至2倍。
- 星蚀：精英随机出现概率提升至默认14％。

星象通过系统消息提示，是当前活动系统，不等同于下面默认关闭的可选环境联动。

### 可选环境互动

以下全部默认关闭，可分别配置：夜晚获取星能额外20％、满月剑气伤害+10％、雷雨剑气连锁最多2个敌人且每个25％伤害、末地领域视觉范围+25％、下界能量衰减翻倍、有效信标恢复未击碎星能盾、紫水晶簇附近共鸣音、下落时剑气最高+50％伤害。

信标联动不会从0免费创建护盾。环境伤害加成仍按对应发射时状态记录。

## 11. 手册、HUD、进度与统计

### 游戏内手册

“星环装备指南”接入Patchouli，不是逐页翻阅的原版成书。右键打开后可分类浏览、搜索和加书签，包含中英文各38个条目、6个分类。

首次重剑自动赠书；丢失后用书+星锭重新合成，也可在独立创造分类获得。命令`/astral help`提供快捷操作帮助。

### HUD与视觉反馈

默认采用紧凑蓝紫主题面板，汇总攻击模式、星能、星能盾、守护屏障和成长信息；连击显示可选，默认关闭。按K进入编辑器，可拖动、滚轮缩放、方向键微调，调整显示开关、透明度、配色并预览保存。

HUD与屏幕效果提供配置开关。能量达到50／100／满值、能量不足、护盾受击／低值／破碎／重铸具有不同提示；音效复用原版资源，并进行服务端限频，避免密集战斗过吵。

本模组独立HUD可以手动避开其他HUD；不保证自动识别并避让所有第三方HUD布局。

### 原版进度

Esc→进度查看“星环之路”。18个可见节点包括根节点，以及星矿、星锭、重剑、远程切换、剑气命中、剑气暴击、100星能、三重斩、全套、星能盾、重铸、精英、试炼、满级熟练度、150连击、单道多杀和残血反杀。

剑气暴击进度仍可达成，不要求恢复暴击浮字或声音。单道多杀通常需要强化穿透或相关连锁条件。

### 原版统计

Esc→统计信息→通用，或`/astral stats`查看11项：剑气发射、命中、击杀、重剑近战击杀、最高连击、单次最高实际暴击伤害、累计星能获得／消耗、护盾吸收、技能使用、完美防御。

暴击记录基于最终伤害事件并截断超过目标当前生命的过量伤害，向上取整；不是单纯显示武器面板或未扣减防御的理论伤害。护盾吸收统计包含星能盾及守护屏障，小数余量会累计，界面显示整数。

## 12. 配置、联机与常见问题

### 配置位置

| 文件                                           | 管理内容                                         |
| -------------------------------------------- | -------------------------------------------- |
| `世界/serverconfig/tutorial_mod-gameplay.toml` | 两阶容量、盾、领域消耗、护甲／韧性／免疫、矿物、精英、强化维修回收、环境、网络与特效预算 |
| `config/tutorial_mod-common.toml`            | 命中／击杀／暴击星能、衰减、普通技能费用、剑气数量／寿命／距离、旧护甲补偿        |
| `config/tutorial_mod-hud.toml`               | 客户端HUD位置、缩放、透明度与屏幕效果                         |

退出世界后修改，重新加载验证。世界级SERVER配置由Forge同步客户端；旧COMMON配置不应被假定具有同样的自动同步行为，整合包应统一分发。即使配置填写更大值，剑气数量与寿命仍分别硬限制为16和100刻。

### 性能和服务端安全

技能由服务端检查存活、旁观、装备、资源与区块。默认技能请求限制每秒8次，普通剑气请求每秒20次；这是安全限速，不等于普通剑气玩法冷却。

服务端装饰粒子默认每区块每刻预算160，支持低特效模式；距离剑气超过48格不生成其客户端装饰星点。离线／换维度清理剑气和临时战斗状态，避免长时间残留。不会为扫描或剑气主动强制加载远处区块。

### 常见问题

**切成统御为什么还有黑暗？**

攻击模式不是领域。先穿齐进阶套装、主手重剑、准备1000星能，再按J。免疫只在10秒领域状态存在时生效；领域结束、喝奶或脱装后可重新获得黑暗。第三方独立视觉效果可能不属于正常药水状态。

**初阶套装为什么放不了领域？**

初阶正常上限250，领域要求进阶套装且默认消耗1000。初阶主要使用普通技能、星能盾与探索。

**剑气为什么挥一下就消失？**

5秒是最大寿命，不是命中后还停留5秒。普通剑气首次命中、碰撞或达到距离限制都会提前消失；需要穿透时强化重剑至+2以上。

**星感知或移动技能没反应？**

穿齐同阶套装，检查星能、按键冲突、使用间隔、是否骑乘／旁观；移动需要安全的已加载落点，不会穿墙或进入液体。

**加入整合包后不能发射？**

确认当前是剑气模式、主手是星环重剑、客户端与服务器版本一致，检查攻击输入冲突、现存剑气是否已到上限、区块是否加载。仍有问题时保留客户端及服务端日志，不要仅凭表现认定某个属性模组导致。

**装附魔描述仍没说明？**

确认使用1.1.1或更新文件、正确的1.20.1 Forge附魔描述和Bookshelf，并检查附魔描述自身显示限制。完整退出重启，不只重载资源。

**星能盾没有黄色心？**

这是独立护盾，在HUD中显示，不是金苹果吸收生命，也不是永久增加最大生命。

**为什么物品栏图标和穿戴外形不完全相同？**

物品图标是二维展示，穿戴外观来自对应三维盔甲模型，二者使用不同资源；这本身不是贴图错乱。请先确认没有残留旧JAR或覆盖资源包。

**与Apothic Attributes装一起一定数值正常吗？**

已对护甲上限及额外补偿做兼容处理，也测试过1.3.7配Placebo8.6.3；不能推导为所有版本、所有整合包都保证平衡。其他模组可替换伤害公式或叠加自己的属性，应在实际整合包中测试。

## 13. 当前实现边界

本文描述实际入口，不将原始32类建议中的每个子项都视作已交付承诺。当前尤其需要区分：

- 星感知只有最近星矿方向／距离扫描，没有精英／试炼入口扫描、左右声道导航或透视标记。
- 星跃使用R触发短距安全移动，没有双击跳跃触发、一次空中使用、专门水下推进或鞘翅起飞联动。
- 星环传送使用H沿视线寻找安全落点，不是潜行套装技能选择菜单，也不跨维度。
- HUD可手动配置；并非原始列表中每个动画和第三方自动避让项都已实现。
- 环境下落联动增强的是剑气，没有独立“星坠斩”专属动作技能。
- 强化是潜行右键锻造台的固定成本系统，不是概率强化或普通三槽强化配方。
- 悬赏固定10项一次性任务，没有自动轮换、无限刷新或单独阵营声望系统。
- 取消了自定义近战横斩动作及模组专属暴击表现，保留普通挥手与暴击数值计算。

因此，本模组可以作为完整的装备—战斗—成长—挑战玩法使用，但不应宣传为“原始32类中的所有细节均已实现”。后续扩展应以新版本实际代码与测试结果更新本文。
