# 1.1.5：每日悬赏

“每日”按主世界游戏日计算：每24000刻一天，正常20TPS下约20分钟，睡觉推进到下一天也会刷新；不是现实零点。不改变十项任务目标，重复提供同一组任务，不随机轮换。

进入新的一天，接取状态、任务进度与领奖状态全部清空，需要重新接取；未领取奖励作废。每项每天最多领奖一次。同一天死亡／重登保留状态；离线跨天只提供当前一轮，不补发历史奖励。倒调时间不会重复刷新，需达到超过已记录游戏日的新一天；管理员主动快进到新游戏日会触发刷新。

升级时既有任务状态保留至下一次游戏日刷新。界面打开期间也每秒检查并同步跨日变化；接取、记录、领奖前均服务端核对当前日期。
