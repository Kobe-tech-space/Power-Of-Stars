# 移动技能与重铸提示

- G星盾重铸无冷却，基础消耗150星能，仅在星能盾未满时使用。它修复的是50点星能盾，不是统御的1000点守护屏障。满盾时明确提示，不扣星能。
- R冲刺无技能冷却，基础消耗20星能，水平前进最多3.5格，低头不会再把冲刺方向指向脚下地面。
- H瞬移无技能冷却，基础消耗40星能，沿视线安全移动最多8格。视线直接指向脚下地面或墙壁时可能没有安全路径，提示受阻且不扣星能。
- N星感知仍保留5秒间隔，避免频繁扫描造成性能问题。

移动需要同阶完整四件套、足够星能且不在载具上。继续检查碰撞、区块、液体、世界边界，不允许穿墙。强化仍可降低实际星能消耗。

旧存档里的R/H冷却时间不再生效；成功移动后清理对应旧时间戳。保留每游戏刻最多一次成功移动和原有技能包频率限制，这些属于服务端安全保护，不是技能冷却。
